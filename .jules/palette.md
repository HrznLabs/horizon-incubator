## 2025-08-02 - Custom scrollbars for dark-themed containers
**Learning:** Default browser scrollbars often look jarring and out-of-place on dark-themed interfaces when elements overflow, breaking immersion.
**Action:** Always implement custom scrollbar styles (using both `scrollbar-color` and `::-webkit-scrollbar`) that match the application's accent colors for horizontally scrollable containers (like code blocks or diagrams) to maintain visual polish.
