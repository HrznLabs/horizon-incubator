## 2025-02-17 - Clickjacking Navigation Trap Bypass
**Vulnerability:** The anti-clickjacking frame-buster script used `top.location = self.location`, which is vulnerable to navigation trapping. Attackers can bypass this protection by using the `onbeforeunload` event or returning a 204 No Content response to cancel the navigation while keeping the iframe loaded.
**Learning:** Using assignment to `location` pushes a new entry to the history stack, which can be interrupted. The CSP hash must also be explicitly regenerated and updated whenever an inline script block is modified to prevent the browser from blocking the frame-buster script itself.
**Prevention:** Always use `window.top.location.replace(window.self.location.href)` for frame-busting scripts to overwrite the history state and mitigate navigation trapping bypasses. Maintain alignment between script contents and CSP headers.
